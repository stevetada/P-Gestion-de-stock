# P-Gestion-de-stock
FRONTEND Application web de gestion de stock conçue pour un restaurant-bar, permettant de suivre efficacement les produits, les entrées et sorties de stock ainsi que les mouvements liés à l’activité de l’établissement.  Le projet a été développé avec React.js, JavaScript, Vite et SQL, avec Postman utilisé pour tester et valider les API.
